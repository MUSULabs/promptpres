# คู่มือติดป้าย N1/N2 v1.0

คู่มือนี้บอกว่า **คนดูวิดีโอแล้วติดป้ายอะไร เมื่อไร** ไม่ได้บอกว่าพฤติกรรมใดดีหรือไม่ดี การตัดสินคุณค่าอยู่ในรูบริกระดับคลิปที่ผู้เชี่ยวชาญทบทวนแล้วเท่านั้น

## 0. กติกาทั่วไป

| เรื่อง | กติกา |
|---|---|
| หน่วยติดป้าย | **ช่วงเวลา (span)** ใน ELAN ความละเอียด 0.1 วินาที · เวลาเป็นวินาที**นับจาก 0 ของไฟล์วิดีโอปิดบังที่ผู้ติดป้ายได้รับจริง** (`<blind_id>.mp4`) ไม่ใช่เวลาของไฟล์ต้นฉบับ WebM ที่ผู้ติดป้ายไม่เห็น · ต้องเป็นไปตาม `0 ≤ start_s < end_s` · ผู้ดูแลข้อมูล (custodian) แปลงเป็นเวลาต้นฉบับภายหลังด้วย `source_offset_s` จาก manifest ส่วนตัว (`EXPERIMENT_PROTOCOL_V1.md` §4.4) · ระบบแปลงเป็นหน้าต่างภายหลัง — ผู้ติดป้ายไม่ติดทีละหน้าต่าง |

| สิ่งที่ซ่อนจากผู้ติดป้าย | ชื่อฉาก (S01–S12) และคำสั่งฉาก · ผลของระบบหรือ AI · ป้ายของผู้ติดป้ายคนอื่น · ไฟล์ส่งให้ผู้ติดป้ายใช้รหัสปิดบัง (`blind_id`) เท่านั้น · เรียกการติดป้ายนี้ว่า **independent, scenario-masked, AI-hidden and peer-label-hidden** ไม่เรียกว่า blind เพราะผู้ติดป้ายเป็นสมาชิกทีม รู้สมมติฐานการวิจัย และอาจจำผู้พูดหรือคลิปบางคลิปได้ (รายงานเป็นข้อจำกัด) |

| ความมั่นใจ | ใส่ `confidence` 1–3 ต่อช่วง (1 = เดา, 3 = ชัด) — ไม่บังคับใน pilot แต่แนะนำ |

## 1. N1 — พฤติกรรมมือ

### 1.1 คำถามตัดสิน (ถามตามลำดับ หยุดที่ข้อแรกที่ตอบ "ใช่")

1. มองเห็นมือ **ทั้งสองข้าง** ไม่พอจะตัดสิน (ถูกบัง อยู่หลังตัว หลุดเฟรม เบลอจนไม่เห็นรูปมือ) → ติด `UNOBSERVABLE` **ตรงช่วงเวลาต่อเนื่องนั้นพอดี**: เริ่มเมื่อมือข้างสุดท้ายที่ยังตัดสินได้หายไป จบเมื่อมือข้างใดข้างหนึ่งกลับมาตัดสินได้ (ไม่ใช้กติกา "มากกว่าครึ่งช่วง" · กติกา > 50% ใช้เฉพาะตอนระบบแปลงช่วงเป็นหน้าต่างภายหลังใน Phase 2)
2. มือสัมผัสตัวเอง เสื้อผ้า ผม แว่น ใบหน้า หรือถู/บีบมือตัวเอง หรือจัด/พับ/โบก/เล่นกระดาษ ปากกา หรือสิ่งของ → `ADAPTOR_MANIPULATION`
3. มือหรือแขนเคลื่อนออกจากท่าพักเข้าสู่พื้นที่ด้านหน้าลำตัว (ราวระดับเอวถึงไหล่ หรือออกด้านข้าง) แล้วทำท่า (เตรียม → ทำท่า → คืน) ระหว่างพูด → `GESTURE`
4. นอกนั้น (มือพัก กุมมือ แนบลำตัว ถือโน้ตนิ่ง ขยับปรับท่าเล็กน้อยไม่เกิน 0.5 วินาที) → `REST_OR_HOLD`

ถ้ามือข้างหนึ่งทำ `GESTURE` และอีกข้างถือโน้ตนิ่ง → `GESTURE` + `holding_notes` · ถ้าข้างหนึ่งทำ `ADAPTOR_MANIPULATION` และอีกข้าง `GESTURE` พร้อมกัน → `ADAPTOR_MANIPULATION` (ข้อ 2 มาก่อนข้อ 3) และตั้ง `ambiguous: true` ถ้าแยกไม่ออก

### 1.2 นิยามและตัวอย่าง

| ป้าย | นิยามเชิงสังเกต | ตัวอย่างบวก | ตัวอย่างลบ (ไม่ใช่ป้ายนี้) |
|---|---|---|---|
| `GESTURE` | การเคลื่อนไหวมือ/แขนในพื้นที่ท่าทางที่สังเกตได้ว่าเป็นท่าประกอบการพูด ไม่ต้องรู้ว่าสื่อความหมายอะไร | ผายมือ ชี้ นับนิ้ว ยกมือขึ้นลงตามจังหวะคำ (beat) วาดรูปร่างในอากาศ ใช้มือข้างที่ว่างขณะอีกข้างถือโน้ต | แขนแกว่งตามการโยกตัว (ใช้ `REST_OR_HOLD` + บันทึกใน `evidence_note`) · ยกกระดาษขึ้นอ่าน (`REST_OR_HOLD` + `holding_notes`) · เกาหัว (`ADAPTOR_MANIPULATION`) |
| `REST_OR_HOLD` | พักมือ กุมมือ วางมือแนบลำตัว หรือถือโน้ต/สิ่งของโดยไม่จัดหรือเล่นซ้ำ | กุมมือหน้าท้อง แขนห้อยข้างตัว สองมือถือกระดาษนิ่ง เลื่อนกระดาษขึ้นครั้งเดียวเพื่ออ่าน | ถูมือไปมา (`ADAPTOR_MANIPULATION`) · ซ่อนมือหลังตัว (`UNOBSERVABLE`) |
| `ADAPTOR_MANIPULATION` | สัมผัสตัว/เสื้อผ้า/ผม/แว่น/ใบหน้า หรือจัด ถู บีบ เล่นกระดาษ ปากกา หรือสิ่งของ | จับเสื้อที่อก ถูหรือบิดมือ ดันแว่น ทัดผม ม้วนหรือโบกกระดาษ หมุนปากกา | ถือกระดาษนิ่ง (`REST_OR_HOLD`) · พลิกหน้ากระดาษครั้งเดียวเพื่ออ่านต่อ (`REST_OR_HOLD` + `holding_notes`) |
| `UNOBSERVABLE` | มองเห็นมือไม่พอจะตัดสินทั้งสองข้าง | มือไพล่หลัง มือต่ำกว่าขอบเฟรม กระดาษหรือแฟ้มบังมือทั้งสองข้าง | เห็นมือข้างเดียว (ตัดสินจากข้างที่เห็น + `one_hand_hidden`) · ภาพมืดแต่ยังเห็นรูปมือ (ตัดสินได้) |

**ข้อห้ามการตีความ:** `REST_OR_HOLD` ไม่ใช่ "ไม่ได้ใช้มือ" ในเชิงลบ · `GESTURE` มากไม่ได้แปลว่าดี · `repetitive` ไม่ได้แปลว่าไม่ดี

### 1.3 Flags

| Flag | ติดเมื่อ | หมายเหตุ |
|---|---|---|
| `holding_notes` | มืออย่างน้อยข้างหนึ่งถือกระดาษ โน้ต แฟ้ม หรืออุปกรณ์ | ใช้ร่วมกับป้ายหลักใดก็ได้ ยกเว้นเมื่อมองไม่เห็นว่าถืออะไร |
| `one_hand_hidden` | เห็นมือเพียงข้างเดียว | ป้ายหลักตัดสินจากข้างที่เห็น |
| `repetitive` | ท่าหรือการเคลื่อนไหวรูปแบบเดิมซ้ำต่อเนื่องอย่างน้อย 3 รอบ | ติดได้ทั้งกับ `GESTURE` (เช่น beat ซ้ำตามจังหวะคำ) และ `ADAPTOR_MANIPULATION` · ไม่ใช่การตัดสินคุณค่า |

**ความกำกวม (ไม่ใช่ flag):** ถ้าตัดสินระหว่างสองป้ายหลักไม่ได้ทั้งที่เห็นภาพชัด ให้ตั้ง `ambiguous: true` ที่ช่วงป้ายหลักนั้น ช่วงที่ `ambiguous: true` ไม่ใช้ฝึกและไม่นับในตัวชี้วัดหลักของโมเดล แต่รายงานจำนวน

### 1.4 ความเข้ม (optional)

ติดเฉพาะเมื่อป้ายหลักเป็น `GESTURE` หรือ `ADAPTOR_MANIPULATION` ให้ตัดสินจากระยะ ความเร็ว และพื้นที่ที่มือใช้ เทียบกับขนาดลำตัวของผู้พูดคนนั้น โดยดูคลิปอ้างอิง (anchor) ที่ทีมเลือกหลัง pilot

- `LOW` = ขยับในระยะสั้น ใกล้ลำตัว ความเร็วต่ำ
- `MODERATE` = ขยับชัดเจนในพื้นที่หน้าลำตัว ความเร็วปานกลาง
- `HIGH` = ขยับกว้างเกินความกว้างไหล่ หรือเร็ว หรือใช้สองมือพร้อมกันเต็มพื้นที่

เก็บป้ายความเข้มไว้ใช้ต่อเฉพาะเมื่อ**ค่ามัธยฐานของ quadratic-weighted Cohen's κ รายคู่ (A1–A2, A1–A3, A2–A3)** ใน pilot ≥ 0.70 (รายงานทั้งสามค่า; `EXPERIMENT_PROTOCOL_V1.md` §4.1) · ไม่ว่าผลจะเป็นอย่างไร ระบบจะคำนวณค่าต่อเนื่องเสมอ

### 1.5 Exploratory (human-only)

ติดหลังติด `N1_function` เสร็จแล้ว และติดเฉพาะช่วง `GESTURE`/`ADAPTOR_MANIPULATION` ถ้าเห็นชัดเท่านั้น ผลนี้ใช้เป็นผลเชิงสำรวจหรือคำอธิบายในรูบริก ห้ามเคลมว่าโมเดลจำแนกได้ จนกว่าจะผ่านเงื่อนไขใน `SCOPE_FREEZE_V1.md` §2

- `MESSAGE_SUPPORTING` = ท่าที่ผู้ติดป้ายเห็นว่าช่วยเน้นหรือแสดงสิ่งที่กำลังพูด (เช่น นับนิ้วตอนพูดจำนวนข้อ)
- `POTENTIALLY_DISTRACTING` = ท่าที่ผู้ติดป้ายเห็นว่าอาจดึงความสนใจออกจากสาร
- `UNCERTAIN` = ไม่แน่ใจ

## 2. N2 — ทิศทางการมองเทียบแนวกล้อง

ผู้ติดป้ายตัดสิน **ทิศทางของศีรษะและดวงตารวมกัน** เทียบกับกล้อง ไม่ใช่การสบตาผู้ฟัง (ไม่มีผู้ฟังจริงในคลิป)

### 2.1 คำถามตัดสิน

1. มองไม่เห็นใบหน้าหรือดวงตาพอจะบอกทิศ (หน้าหลุดเฟรม ถูกกระดาษบัง หันหลัง ภาพมืดหรือเบลอจนไม่เห็นตำแหน่งตา) → `UNOBSERVABLE`
2. สายตาหรือศีรษะมุ่งลงไปที่โน้ต กระดาษ หรือบริเวณต่ำกว่าแนวกล้องที่ผู้พูดถือ/วางโน้ต → `NOTES`
3. ศีรษะหรือสายตามุ่งไปทางอื่นที่ไม่ใช่บริเวณกล้อง (หันข้าง เงย มองจอหรือสไลด์ มองพื้นที่ไม่มีโน้ต) → `OTHER`
4. ศีรษะและสายตามุ่งมาบริเวณกล้อง → `CAMERA_REGION`

### 2.2 นิยามและตัวอย่าง

| ป้าย | ตัวอย่างบวก | ตัวอย่างลบ |
|---|---|---|
| `CAMERA_REGION` | พูดโดยหันหน้าและสายตามาที่กล้อง แม้ศีรษะเอียงเล็กน้อย | หน้าตรงแต่ตาลงอ่านกระดาษ (`NOTES`) |
| `NOTES` | ก้มอ่านกระดาษ · ศีรษะเกือบตรงแต่ตาลดลงอ่าน · เหลือบลงดูโน้ตสั้น ๆ ≥ 0.3 วินาที | มองพื้นโดยไม่ได้ถือหรือวางโน้ต (`OTHER`) · หลับตาหรือกะพริบ (ไม่เปลี่ยนป้าย) |
| `OTHER` | หันข้าง มองเพดาน มองไปทางจอ | หันข้างเล็กน้อยแต่ตายังมาที่กล้อง (`CAMERA_REGION`) |
| `UNOBSERVABLE` | กระดาษบังหน้า หน้าหลุดขอบเฟรม | หน้ามืดแต่ยังเห็นตำแหน่งตา (ตัดสินได้ ตั้ง `ambiguous: true` ถ้าไม่แน่ใจ) |

### 2.3 การเหลือบกับการอ่านต่อเนื่อง

ติดป้าย `NOTES` ทุกครั้งตามขอบเวลาจริง ไม่ต้องแยกป้าย "เหลือบ" กับ "อ่าน" ระบบจะเก็บระยะเวลาต่อเนื่องของแต่ละช่วงไว้ การกำหนดว่ากี่วินาทีเป็น "เหลือบ" หรือ "อ่านต่อเนื่อง" เป็นคำถามของรูบริก ซึ่งต้องรอผล pilot และการทบทวนของผู้เชี่ยวชาญ (ห้ามใช้ 2 วินาที หรือ 5 วินาที เป็นกฎสุดท้ายก่อนหน้านั้น)

กะพริบตาไม่นับเป็นการเปลี่ยนป้าย · ช่วงเปลี่ยนทิศที่สั้นกว่า 0.3 วินาทีให้รวมเข้าช่วงข้างเคียง

## 3. กรณีก้ำกึ่งที่ตกลงไว้

## 4. ขั้นตอน pilot และการแก้ความเห็นต่าง

1. สมาชิกทั้ง 3 คนติดป้าย pilot 15 รายการ **อย่างอิสระ** ห้ามคุยกันระหว่างติด และห้ามดู AI suggestion · รายการ pilot อยู่ใน manifest ส่วนตัวนอก git (ผู้ติดป้ายได้รับเฉพาะไฟล์ `<blind_id>.mp4`; ใน repo มีแค่ `manifests/pilot_manifest_TEMPLATE.csv`) · รายการถูกเลือกแบบเจาะจงเพื่อให้ครอบคลุมคู่มือ (purposive) ค่า κ ของ pilot จึงใช้ปรับคู่มือเท่านั้น ไม่ใช่ค่าความเชื่อมั่นของประชากร
2. คำนวณ agreement ตาม `EXPERIMENT_PROTOCOL_V1.md` §4 ก่อนประชุม
3. ประชุมดูเฉพาะ confusion และช่วงที่ไม่ตรงกัน แก้คู่มือ เพิ่มกรณีก้ำกึ่ง เลือก anchor examples แล้วออกเวอร์ชันใหม่ (v1.1 …)
4. เกณฑ์: ≥ 0.70 ล็อกคู่มือ · 0.60–0.69 แก้คู่มือแล้วทำ pilot ซ้ำ (ใช้ชุดคลิปสำรองที่ไม่เคยติด) · < 0.60 รวมคลาส (ลำดับ: `ADAPTOR_MANIPULATION` → flag ของ `REST_OR_HOLD`/`GESTURE`; `HIGH` → `MODERATE`; `OTHER` → `NOT_CAMERA`) ลดความซับซ้อน หรือยกเลิก label ที่เป็น optional
5. หลังล็อกคู่มือ: GOLD **ทุกรายการ** ให้ 2 คนติดอย่างอิสระ (100%; ค่า 20–30% ในเอกสารอ้างอิงเป็นเพียงขั้นต่ำที่พบทั่วไป) คนที่ 3 ตัดสินจุดที่ขัดแย้ง (adjudication) โดยเห็นป้ายทั้งสองแต่ไม่เห็นผล AI
   - ป้ายอิสระของแต่ละคน (`record_role: independent`) **ห้ามแก้หลังส่ง**
   - การตัดสินสร้าง **record ใหม่** (`record_role: consensus`, `consensus_basis: adjudicated`, `adjudicator_id`, `source_annotation_ids`) ไม่เขียนทับของเดิม · ช่วงที่สองคนตรงกันก็สร้าง consensus record (`consensus_basis: agreed`)
   - ค่า agreement คำนวณจากป้ายอิสระก่อนตัดสินเท่านั้น · โมเดลฝึกและประเมินด้วย consensus records
6. ถ้าคู่มือเปลี่ยนหลัง pilot: ป้าย pilot ต้อง**ติดใหม่อย่างอิสระด้วยคู่มือฉบับสุดท้าย** หรือ**ไม่ใช้**ในการฝึกและประเมินโมเดล
7. ผู้ติดป้ายไม่ควรติดป้ายคลิปของตัวเอง (P18–P20) ในชุด GOLD
